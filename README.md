# Bohemia

Feudální strategie v prohlížeči. Buduj vesnice, hradiště, tvrze a hrady, rozšiřuj rodový majetek
a prestiž a udrž svůj rod naživu – roky 500–1500 za jediný skutečný rok.

**Spuštění: 1. 1. 2027**

## Vývoj

```bash
npm install
npm run dev   # http://localhost:3010
```
